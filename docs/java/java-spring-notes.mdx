## Java 基础

### isEmpty()

```java title="IsEmptyDemo.java" showLineNumbers
List<String> list1 = new ArrayList<>();     // 空列表
list1.isEmpty();  // true

List<String> list2 = Arrays.asList("a");    // 有 1 个元素
list2.isEmpty();  // false

List<String> list3 = null;                  // 这是 null，不是空列表
list3.isEmpty();  // 报错 NullPointerException

// 不确定是否为 null 时，先判空；Spring 提供了现成的工具方法
boolean empty = list3 == null || list3.isEmpty();
boolean empty2 = CollectionUtils.isEmpty(list3);  // org.springframework.util.CollectionUtils
```

### 常用修饰符与关键字

- `private`：只能在本类内部访问

```java title="Books.java / Main.java" showLineNumbers {20}
// Books.java
public class Books {
    private String bookName;
    private String author;
    private String publisher;
    private String isbn;  // 字段名使用小驼峰，不要全大写

    public void setBookName(String bookName) {
        this.bookName = bookName;
    }

    public String getBookName() {
        return bookName;
    }
}

// Main.java
Books book = new Books();

String name = book.bookName;      // 编译报错：bookName has private access in Books，需要主动暴露
String ok = book.getBookName();   // 通过 getter 访问
```

- `final`：一旦赋值不可再修改

```java title="Main.java" showLineNumbers
final Integer age = 20;
age = 30;  // 报错
```

`final` 修饰引用类型时，限制的是「引用不能指向别的对象」，对象内部的内容仍然可以修改。

- `interface`：只定义「要做什么」（方法签名），具体实现交给别人（比如 MyBatis 根据接口自动生成实现类）
- `static`：不用创建对象就能访问

```java title="People.java / Main.java" showLineNumbers
// People.java
public class People {
    private static int count = 0;

    public static int addCount() {
        return ++count;
    }
}

// Main.java
People.addCount();  // 不需要将类实例化
```

- `public`：任何地方都可以访问

### 数据类型

#### 高精度与日期类型（常用引用类型）

- `BigDecimal`：高精度数字（财务计算必备，解决浮点精度丢失），创建时使用字符串构造 `new BigDecimal("0.1")`，不要传 `double`
- `LocalDateTime`：本地日期时间（Java 8+ 推荐，替代 `Date` 和 `Calendar`）
- `BigInteger`：超大整数（比 `long` 还大时使用）

#### Java 基本数据类型

- `byte`：8 位，-128~127，省内存用
- `short`：16 位，较少用
- `int`：32 位，**默认整数，最常用**
- `long`：64 位，赋值加 `L`（如 `100L`）
- `float`：32 位，赋值加 `F`（如 `3.14F`）
- `double`：64 位，**默认小数，最常用**
- `char`：16 位，单引号，存单个字符（如 `'A'`、`'中'`）
- `boolean`：仅 `true` / `false`

#### 对应的包装类（引用类型）

基本类型 → 包装类（用于集合、泛型等场景）：

| 基本类型 | 包装类 |
| --- | --- |
| `byte` | `Byte` |
| `short` | `Short` |
| `int` | `Integer` |
| `long` | `Long` |
| `float` | `Float` |
| `double` | `Double` |
| `char` | `Character` |
| `boolean` | `Boolean` |

### MyBatis XML 写法

XML 文件放在 `resources/mapper/` 目录下，同时需要在配置文件中告诉 MyBatis 去哪里找它们，否则会报 `Invalid bound statement (not found)`：

```yaml title="application.yml" showLineNumbers
mybatis:
  mapper-locations: classpath:mapper/*.xml
  configuration:
    map-underscore-to-camel-case: true  # 数据库的 user_name 自动映射到 Java 的 userName
```

```xml title="UserMapper.xml" showLineNumbers
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.springboot_test.mapper.UserMapper">
    <!-- namespace 必填，必须对应目标 Mapper 接口的完整包路径 -->
    <!-- select 必须指定 resultType 或 resultMap（新增、修改、删除不需要返回值） -->

    <!-- 不含参数的查询 -->
    <select id="userIdAll" resultType="Integer">
        select id from user
    </select>

    <!-- 含参数的查询 -->
    <select id="selectUserById" resultType="Integer">
        select id from user where id = #{id}
    </select>

    <!-- 新增 -->
    <insert id="insertUser">
        insert into user(name) values(#{name})
    </insert>

    <!-- 修改 -->
    <update id="updateUser">
        update user set name = #{name} where id = #{id}
    </update>

    <!-- 删除 -->
    <delete id="deleteUser">
        delete from user where id = #{id}
    </delete>
</mapper>
```

<Callout type="warning" title="#{} 与 ${} 的区别">
`#{}` 使用预编译参数，可以防止 SQL 注入；`${}` 是直接拼接字符串，只用于表名、排序字段等无法预编译的场景，且必须自己保证内容可信。
</Callout>

#### 处理一对多时

<Details title="展开查看 resultMap 与两次 SQL 的写法">

`resultMap` 将数据库字段映射进 Java 对象，`collection` 声明 `orders` 字段怎么填充：把数据库的多条记录装进 Java 对象里的 `List` 属性。

```xml title="UserMapper.xml" showLineNumbers {9,10,11}
<resultMap id="userWithOrdersMap" type="com.example.corelearning.dto.UserDto">
    <id property="id" column="id"/>
    <result property="username" column="username"/>
    <result property="age" column="age"/>

    <!-- collection：声明 orders 字段怎么填充 -->
    <!-- column="id"：将查询结果的 id 继续传给下一条 SQL -->
    <!-- select：调用另外的 SQL（OrderMapper 中的 selectByUserId） -->
    <collection property="orders"
                column="id"
                select="com.example.corelearning.mapper.OrderMapper.selectByUserId"/>
</resultMap>
```

第一次 SQL 查询拿到 ID：

```xml title="UserMapper.xml" showLineNumbers
<select id="selectUserWithOrders" resultMap="userWithOrdersMap">
    select id, username, age from user where id = #{id}
</select>
```

第二次 SQL 根据查询到的 ID 获取订单表数据，也就是调用 `com.example.corelearning.mapper.OrderMapper.selectByUserId`：

```xml title="OrderMapper.xml" showLineNumbers
<select id="selectByUserId" resultType="com.example.corelearning.dto.OrderDto">
    select id, user_id, amount, status, created_at
    from orders
    where user_id = #{userId}
</select>
```

这种「先查主表、再按 ID 查子表」的写法，查询单个用户时没有问题；一次查询 N 个用户时会额外执行 N 次子查询（N+1 问题），列表场景建议改用 `JOIN` 一次查出，再用 `collection` 的 `ofType` 配合 `resultMap` 映射。

</Details>

### 统一返回格式封装

**命名规范提醒**：类名应为 `Result`（首字母大写），而不是 `result`。

```java title="Result.java" showLineNumbers
// 基于 Lombok 封装
@Data
public class Result<T> {
    private Integer code;
    private String msg;
    private T data;

    public static <T> Result<T> success(T data) {
        Result<T> result = new Result<>();
        result.setCode(200);
        result.setMsg("操作成功");
        result.setData(data);
        return result;
    }

    // 失败场景，配合全局异常处理器使用
    public static <T> Result<T> fail(Integer code, String msg) {
        Result<T> result = new Result<>();
        result.setCode(code);
        result.setMsg(msg);
        return result;
    }
}
```

### 接口错误统一处理

#### 通用异常处理

```java title="GlobalExceptionHandler.java" showLineNumbers {7,15,22}
@Log4j2  // 日志
@RestControllerAdvice
public class GlobalExceptionHandler {

    // 兜底处理：没有被更具体的处理器匹配到的异常都会进入这里
    // （Spring 会优先选择最匹配的处理器，所以下面的自定义异常不会被它抢走）
    @ExceptionHandler(Exception.class)
    public Result<Void> handleException(Exception e) {
        // 详细信息只写日志，不要把 e.getMessage() 直接返回给前端，避免泄露内部细节
        log.error("服务器内部错误：{}", e.getMessage(), e);
        return Result.fail(500, "服务器内部错误，请稍后重试");
    }

    // 使用自定义业务异常类
    @ExceptionHandler(BusinessException.class)
    public Result<Void> businessError(BusinessException e) {
        log.warn("业务异常：{}", e.getMessage());
        return Result.fail(e.getCode(), e.getMessage());
    }

    // MethodArgumentNotValidException.class 会捕获所有参数校验失败的异常
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<Void> handleValidException(MethodArgumentNotValidException e) {
        FieldError fieldError = e.getBindingResult().getFieldError();
        // getFieldError() 可能为 null（例如类级别的校验失败），需要判空
        String message = fieldError != null ? fieldError.getDefaultMessage() : "参数校验失败";
        log.warn("参数校验失败：{}", message);
        return Result.fail(400, message);
    }
}
```

#### 自定义业务异常类

在业务层使用 `throw new BusinessException(code, message);` 会自动被 `businessError` 方法捕获，返回自定义的错误码和错误信息。

```java title="BusinessException.java" showLineNumbers

        super(message);
        this.code = code;
    }
}
```

```java title="SecurityConfig.java" showLineNumbers {24,26,29,32,36}
// com.example.xxx.config
@Configuration
@RequiredArgsConstructor  // 为 final 字段生成构造器，实现构造器注入
public class SecurityConfig {

    private final JwtAuthenticationFilter jwtAuthenticationFilter;
    private final JwtAuthenticationEntryPoint jwtAuthenticationEntryPoint;

    /**
     * 密码加密器（BCrypt 强哈希，单向不可逆）
     */
    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }

    /**
     * securityFilterChain：所有过滤规则，每个请求都会走到这里
     * HttpSecurity：拦截规则类
     */
    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
                .csrf(AbstractHttpConfigurer::disable)  // 前后端分离项目通常不需要 CSRF，用 JWT 做鉴权
                .sessionManagement(session -> session
                        .sessionCreationPolicy(SessionCreationPolicy.STATELESS)  // 告诉 Spring Security 不使用 Session
                )
                .exceptionHandling(exception -> exception
                        .authenticationEntryPoint(jwtAuthenticationEntryPoint)   // 认证失败时用这个类处理
                )
                .authorizeHttpRequests(auth -> auth
                        .requestMatchers("/user/register", "/user/login").permitAll()  // 这两个接口不需要登录
                        .anyRequest().authenticated()                                  // 其他所有接口都需要登录
                )
                // 在校验表单登录之前插入我们的过滤器
                .addFilterBefore(jwtAuthenticationFilter, UsernamePasswordAuthenticationFilter.class);

        return http.build();
    }
}
```

```java title="JWTUtil.java" showLineNumbers {5,9,14,22,37,55}
@Component
public class JWTUtil {
    // 从 application.yml 读取密钥
    @Value("${jwt.secret-key}")
    private String secretKey;

    // 从 application.yml 读取过期时间（毫秒）
    @Value("${jwt.expire-time}")
    private long expireTime;

    /**
     * 生成签名密钥（HS256 要求密钥不少于 32 字节）
     */
    private SecretKey getKey() {
        return Keys.hmacShaKeyFor(secretKey.getBytes(StandardCharsets.UTF_8));
    }

    /**
     * 生成 token 逻辑
     * @param username 用户名
     */
    public String generateToken(String username, String userId, String role) {
        return Jwts.builder()
                .subject(username)
                .claim("userId", userId)
                .claim("role", role)
                .claim("platform", "web")
                .issuedAt(new Date())
                .expiration(new Date(System.currentTimeMillis() + expireTime))
                .signWith(getKey())
                .compact();
    }

    /**
     * 解析并校验 token，返回载荷；token 非法或已过期会抛出 JwtException
     */
    public Claims parseClaims(String token) {
        return Jwts.parser()
                .verifyWith(getKey())
                .build()
                .parseSignedClaims(token)
                .getPayload();
    }

    /**
     * 从 token 解析用户名
     */
    public String getUsernameFromToken(String token) {
        return parseClaims(token).getSubject();
    }

    /**
     * 验证 token 是否有效
     */
    public boolean validateToken(String token) {
        try {
            parseClaims(token);
            return true;
        } catch (JwtException | IllegalArgumentException e) {
            return false;
        }
    }
}
```

```java title="JwtAuthenticationFilter.java" showLineNumbers {13,16,22,25,32}
@Component
@RequiredArgsConstructor
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private final JWTUtil jwtUtil;

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain) throws ServletException, IOException {

        // 第一步：从请求头取出 Authorization 字段
        String authHeader = request.getHeader("Authorization");

        // 第二步：检查格式是否是 "Bearer xxx"，不是的话直接放行（交给后面的规则处理）
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            filterChain.doFilter(request, response);
            return;
        }

        // 第三步：把 "Bearer " 这个前缀去掉，拿到真正的令牌内容
        String token = authHeader.substring(7);

        // 第四步：校验令牌是否合法
        if (jwtUtil.validateToken(token)) {
            String username = jwtUtil.getUsernameFromToken(token);

            // 第五步：把「这个用户已登录」的信息存进 Spring Security 的上下文
            // 这里暂时没有加载权限；需要按角色控制接口时，在此放入 SimpleGrantedAuthority
            UsernamePasswordAuthenticationToken authentication =
                    new UsernamePasswordAuthenticationToken(username, null, Collections.emptyList());
            SecurityContextHolder.getContext().setAuthentication(authentication);
        }

        // 继续放行，请求进入下一个环节
        filterChain.doFilter(request, response);
    }
}
```

如果需要支持「退出登录 / 踢人下线」，可以在 `validateToken` 通过之后，再用下文的 `RedisUtil` 检查该 token 是否在黑名单中。

```java title="JwtAuthenticationEntryPoint.java" showLineNumbers
// 认证失败处理器：未登录或令牌无效时，返回 401 和 JSON 提示
@Component
@RequiredArgsConstructor
public class JwtAuthenticationEntryPoint implements AuthenticationEntryPoint {

    private final JsonMapper jsonMapper;  // 注入容器中的实例，不需要每次请求都新建

    @Override
    public void commence(HttpServletRequest request,
                         HttpServletResponse response,
                         AuthenticationException authException) throws IOException {

        response.setContentType(MediaType.APPLICATION_JSON_VALUE);  // application/json
        response.setCharacterEncoding("UTF-8");
        response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);    // 401

        Result<Void> result = Result.fail(401, "未登录或令牌已失效，请重新登录");

        response.getWriter().write(jsonMapper.writeValueAsString(result));
    }
}
```

```java title="RedisUtil.java" showLineNumbers {13,21,32,39}
@Component
public class RedisUtil {

    @Autowired
    private StringRedisTemplate redisTemplate;

    @Autowired
    private JsonMapper jsonMapper;

    /**
     * 存值（带过期时间），自动把对象转成 JSON 字符串
     */
    public void set(String key, Object value, long timeout, TimeUnit unit) {
        String json = jsonMapper.writeValueAsString(value);
        redisTemplate.opsForValue().set(key, json, timeout, unit);
    }

    /**
     * 取值，自动把 JSON 字符串转回指定类型的对象
     */
    public <T> T get(String key, Class<T> clazz) {
        String json = redisTemplate.opsForValue().get(key);
        if (json == null) {
            return null;
        }
        return jsonMapper.readValue(json, clazz);
    }

    /**
     * 删除某个 key
     */
    public void delete(String key) {
        redisTemplate.delete(key);
    }

    /**
     * 判断 key 是否存在
     */
    public boolean hasKey(String key) {
        return Boolean.TRUE.equals(redisTemplate.hasKey(key));
    }
}
```

关键点解释：

| 设计 | 原因 |
| --- | --- |
| `set` 方法多了 `timeout` 和 `unit` 两个参数 | 强制要求调用者每次存值时都必须显式指定过期时间（`TimeUnit.MINUTES`、`TimeUnit.HOURS` 这些），避免「忘记设置过期时间导致缓存永久堆积」 |
| `get` 方法用了泛型 `<T>` | 一个方法可以适配任何类型，比如 `redisUtil.get("user:1", UserDto.class)` 就能直接拿到一个 `UserDto` 对象，不需要针对每种类型单独写方法 |
| `jsonMapper.readValue(json, clazz)` | Jackson 提供的反序列化方法，把 JSON 字符串转换回 Java 对象 |

</Details>
