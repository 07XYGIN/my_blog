## Python 基础复习

## enumerate
用于遍历列表/元组/字符串，获取索引和值
`enumerate(iterable, start=0)`
iterable: 任何可迭代对象（列表、元组等）

start: 索引起始值，默认为0

```python
fruits = ['苹果', '香蕉', '橙子']

for index, fruit in enumerate(fruits,start=1):
    print(f"索引: {index}, 水果: {fruit}")

```

`**kwargs`:解包字典

注意：`**kwargs` 后面不能再添加普通参数；普通参数必须放在前面，但后面仍然可以添加 `*args`。

```python
def a(**kwargs):
    print(kwargs)
a(name="张三", age=25, city="北京") #输出这个字典
```

## Pydantic
用于数据校验。
```python
from pydantic import BaseModel, EmailStr, Field, SecretStr, field_validator

# BaseModel 类似 TypeScript 的 interface
# Field 用于声明数值范围、字符串正则等校验规则
# field_validator 用于校验单个字段
# EmailStr 校验邮箱地址，SecretStr 保护敏感字段
# e.g.:

class User(BaseModel):
    username: str = Field(min_length=2, max_length=20, description="用户名")
    email: EmailStr = Field(description="邮箱")
    age: int = Field(ge=0, le=150, description="年龄")
    password: str = Field(min_length=6, description="密码")


"""
min_length: 最小长度
max_length: 最大长度
ge:大于等于
le:小于等于
gt:大于
lt:小于
"""
```

~~~py
from pathlib import Path
import yaml

PROJECT_ROOT = Path(__file__).resolve().parent.parent # 得到项目根目录
def get_yaml(filename: str = "keywords.yaml") -> dict:
    config_path = PROJECT_ROOT / filename
    with open(config_path, "r", encoding="utf-8") as f:
        return yaml.safe_load(f) or {}

getyaml() # {'keywords': ['解脱者'], 'name': ['塞拉斯']}
~~~

## @dataclass
自动生成`__init__`,  `__repr__` , `__eq__`等方法
```python
from dataclasses import dataclass
@dataclass
class toolList:
    name:str
    def get_display_name(self, age):
        obj = {
            "self":self,
            "age":age
        }
        return obj

item = toolList('join')

```
