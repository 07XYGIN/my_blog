## 常用命令

- `git status`：查看 Git 状态。
  - `U`：未被追踪的文件。
  - `A`：新增并暂存的文件。
  - `M`：已修改的文件。
  - `D`：已删除的文件。
  - `R`：重命名的文件（例如 `2.py` → `3.py`）。

- `git add`：提交到暂存区。
- `git commit -m "消息"`：创建本地提交。
- `git push`：将本地分支推送到远程仓库。
- `git pull`：从远程仓库拉取更新。
- `git log`：查看提交历史。
- `git push -u origin <new-branch>`：将新分支推送到远程并建立跟踪关系。
- `git branch`：查看分支（带 `*` 的是当前分支）。
- `git checkout -b <new-branch>`：创建并切换到新分支。
- `git checkout <new-branch>`：切换分支。
- `git merge <new-branch>`：合并分支。

## 处理冲突

```text
 <<<<<<< HEAD
我写的代码(当前分支)
print('main')
 =======
别人写的代码(合并的分支)
print("testtest")
 >>>>>>> branch_test
```

## 暂存改动

- `git stash -u`：暂存所有未提交文件。
- `git stash list`：查看暂存列表。
- `git stash pop`：恢复最近一次暂存。
- `git stash pop "stash@{1}"`：恢复指定的暂存。

## 回滚

- `git revert <commit-id>`：创建一个反向提交，撤销指定提交的改动。
