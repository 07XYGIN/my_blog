## enumerate
用于遍历列表/元组/字符串，获取索引和值
`enumerate(iterable, start=0)`
iterable: 任何可迭代对象（列表、元组等）

start: 索引起始值，默认为0

```python
fruits = ['苹果', '香蕉', '橙子']

for index, fruit in enumerate(fruits,start=1):
    print(f"索引: {index}, 水果: {fruit}")

```

## Pydantic
用于数据校验。
```python
from pydantic import BaseModel, EmailStr, Field, SecretStr, field_validator

# BaseModel 类似 TypeScript 的 interface
# Field 用于声明数值范围、字符串正则等校验规则
# field_validator 用于校验单个字段
# EmailStr 校验邮箱地址，SecretStr 保护敏感字段
# e.g.:

class User(BaseModel):
    username: str = Field(min_length=2, max_length=20, description="用户名")
    email: EmailStr = Field(description="邮箱")
    age: int = Field(ge=0, le=150, description="年龄")
    password: str = Field(min_length=6, description="密码")


"""
min_length: 最小长度
max_length: 最大长度
ge:大于等于
le:小于等于
gt:大于
lt:小于
"""
```

## '*args'与'**kwargs'
如果处理数量不确定的同类型参数,使用`*` 返回元组
~~~python
def concat(*strings):
    result = ""
    for str in strings:
        result +=str
    return result
~~~

如果处理数量不确定的字典，使用`**` 返回字典
~~~python
def requests_send(url,**requestOptions):
    timeout = requestOptions.get("timeout")
    method = requestOptions.get("methods")
    header = requestOptions.get("header")
    return f"url={url},timeout:{timeout},method:{method},header:{header}"
~~~


## 自定义装饰器
装饰器本质上就是一个接收函数、返回函数的高阶函数，用来在不修改原函数代码的前提下，给它"包"上一层额外的功能。
~~~py
def log(func):
    def wrapper(*args, **kwargs):
        print(f"调用参数: args={args}, kwargs={kwargs}")
        return func(*args, **kwargs)
    return wrapper

@log # 相当于create_user = log(create_user)
def create_user(name, age, city='Beijing', vip=False):
    print(f"{name}, {age}, {city}, VIP={vip}")

create_user('job', 18, city='Shanghai', vip=True) # 调用参数: args=('job', 18), kwargs={'city': 'Shanghai', 'vip': True}

~~~
<Details title="有参数的装饰器">
~~~py
from functools import wraps

def my_decorator(**kwargs):        # 第1层：用**kwargs收集任意关键字参数
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kw):
            print(f"装饰器配置: {kwargs}")
            return func(*args, **kw)
        return wrapper
    return decorator

@my_decorator(times=3, delay=2, name="测试")
def risky_function():
    return "执行成功"

risky_function()
# 装饰器配置: {'times': 3, 'delay': 2, 'name': '测试'}
~~~
