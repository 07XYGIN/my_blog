## 对象、封装与类成员

```java title="JavaBasicsDemo.java" showLineNumbers
public class JavaBasicsDemo {
    public static void main(String[] args) {
        // 空集合已有对象；null 需要先判空再调用方法
        List<String> empty = new ArrayList<>();
        List<String> missing = null;
        System.out.println(empty.isEmpty());
        System.out.println(missing == null || missing.isEmpty());

        Book book = new Book();
        book.setBookName("Java 笔记");
        System.out.println(book.getBookName());

        // final 固定引用，列表中的元素仍可修改
        final List<String> names = new ArrayList<>();
        names.add("Gin");
        System.out.println(names);
        System.out.println(Counter.addCount());

        BigDecimal amount = new BigDecimal("0.1").add(new BigDecimal("0.2"));
        BigInteger large = new BigInteger("9223372036854775808");
        System.out.println(amount);
        System.out.println(large);
        System.out.println(LocalDateTime.now());
        System.out.println(Instant.now());
    }

    static final class Book {
        private String bookName;

        public String getBookName() {
            return bookName;
        }

        public void setBookName(String bookName) {
            this.bookName = bookName;
        }
    }

    static final class Counter {
        private static int count; // 同一类的所有实例共享这个字段

        public static int addCount() {
            return ++count;
        }
    }
}
```

## 封装、修饰符与接口

| 关键字 | 含义与边界 |
| --- | --- |
| `private` | 限制成员访问，用 getter、setter 或行为方法控制外部操作 |
| `public` | 对可见的调用者公开；跨包访问还受包、模块和外层类型可见性约束 |
| `final` | 变量只能赋值一次；修饰类时不能继承，修饰方法时不能重写 |
| `static` | 成员属于类，可通过类名访问，不需要先创建实例 |
| `interface` | 定义类型契约，类通过 `implements` 实现它 |

```java title="接口与实现" showLineNumbers
interface Formatter {
    String format(String value);

    default String formatOrEmpty(String value) {
        return value == null ? "" : format(value);
    }
}

class TrimFormatter implements Formatter {
    @Override
    public String format(String value) {
        return value.strip(); // 同时去掉首尾的 Unicode 空白
    }
}
```

## 基本类型与包装类

| 基本类型 | 特点 | 包装类 |
| --- | --- | --- |
| `byte` | 8 位有符号整数，-128～127 | `Byte` |
| `short` | 16 位有符号整数 | `Short` |
| `int` | 32 位有符号整数，整数字面量通常默认用它 | `Integer` |
| `long` | 64 位有符号整数，字面量可加 `L`，如 `100L` | `Long` |
| `float` | 32 位浮点数，字面量加 `F`，如 `3.14F` | `Float` |
| `double` | 64 位浮点数，小数字面量的默认类型 | `Double` |
| `char` | 一个 16 位 UTF-16 代码单元，使用单引号 | `Character` |
| `boolean` | `true` 或 `false` | `Boolean` |

```java title="类型转换" showLineNumbers
int number = Integer.parseInt("42");
long id = Long.parseLong("1234567890123");
String text = String.valueOf(number);
List<Integer> numbers = List.of(1, 2, 3); // 泛型参数使用包装类

long large = 2_147_483_648L;
// 超出 int 范围时抛 ArithmeticException，避免强转导致截断
try {
    int small = Math.toIntExact(large);
    System.out.println(small);
} catch (ArithmeticException e) {
    System.out.println("超出 int 范围");
}
```

## List 增删、切片与数组转换

List<String> names = new ArrayList<>(List.of("Gin", "Alice", "Bob"));

List<String> copy = new ArrayList<>(Arrays.asList(array));

List<String> snapshot = List.copyOf(names); // 不可修改的快照，不接收 null 元素

## Set 去重与集合运算

```java title="去重、交集、差集" showLineNumbers
List<String> names = List.of("Gin", "Alice", "Gin");
List<String> unique = new ArrayList<>(new LinkedHashSet<>(names)); // 保留首次出现顺序

Set<Integer> left = new HashSet<>(Set.of(1, 2, 3));
Set<Integer> right = Set.of(2, 3, 4);

Set<Integer> intersection = new HashSet<>(left);
intersection.retainAll(right); // [2, 3]，不修改 left
Set<Integer> difference = new HashSet<>(left);
difference.removeAll(right);   // [1]
Set<Integer> union = new HashSet<>(left);
union.addAll(right);          // [1, 2, 3, 4]，HashSet 不保证顺序
```

## Map 读取、累计与分组

Map<String, Integer> counts = new HashMap<>();
for (String word : List.of("java", "python", "java")) {
    counts.merge(word, 1, Integer::sum); // 不存在时写入 1，否则累加

Map<String, List<String>> groups = new LinkedHashMap<>();

    groups.computeIfAbsent(name.substring(0, 1), key -> new ArrayList<>()).add(name);

counts.forEach((key, value) -> System.out.println(key + ": " + value));

## Stream 筛选、排序与转换

```java title="Stream 数据整理" showLineNumbers
record User(long id, String name, int age, String city) {}

List<User> users = List.of(
    new User(1L, "Gin", 24, "上海"),
    new User(2L, "Alice", 28, "北京"),
    new User(3L, "Bob", 17, "上海")
);

List<String> names = users.stream()
    .filter(user -> user.age() >= 18)
    .sorted(Comparator.comparingInt(User::age).reversed())
    .map(User::name)
    .toList(); // Java 16+，结果不可修改

Map<String, List<User>> byCity = users.stream()
    .collect(Collectors.groupingBy(User::city));
Map<Long, User> byId = users.stream()
    // ID 重复时保留先出现的对象，避免 toMap 抛异常
    .collect(Collectors.toMap(User::id, user -> user, (first, second) -> first));
int totalAge = users.stream().mapToInt(User::age).sum();
String joined = users.stream().map(User::name).collect(Collectors.joining(", "));
```

enum Status {

class Lists {
    // 返回 Optional，统一处理空列表

## 文件读写与自动关闭资源

```java title="UTF-8 文件读写" showLineNumbers
Path directory = Files.createTempDirectory("java-notes-");
Path file = directory.resolve("notes.txt");
try {
    Files.writeString(file, "Java\nRedis\n", StandardCharsets.UTF_8);
    String text = Files.readString(file, StandardCharsets.UTF_8);

    // Files.lines 返回持有文件句柄的 Stream，用完自动关闭
    try (Stream<String> lines = Files.lines(file, StandardCharsets.UTF_8)) {
        List<String> nonEmpty = lines.filter(line -> !line.isBlank()).toList();
        System.out.println(nonEmpty);
    }
} finally {
    Files.deleteIfExists(file);
    Files.deleteIfExists(directory);
}
```
