浏览器拿到 HTML 后会构建 DOM 与 CSSOM；解析到普通 `script` 时，HTML 解析可能暂停，JavaScript 代码交给 V8 等引擎处理。理解这个过程，有助于判断脚本加载策略与页面性能问题。

## 闭包与作用域

闭包让内部函数保留对外层作用域变量的引用，即使外层函数已经执行结束。

```js
function createCounter() {
  let count = 0;

  return function increment() {
    count += 1;
    return count;
  };
}

const counter = createCounter();
counter(); // 1
counter(); // 2
```

适合用闭包保存私有状态，但也要避免在长期存活的回调中无意引用大型对象。

## 类、继承与 super

子类构造器必须先调用 `super()`，父类才能完成实例初始化，之后才可以访问 `this`。

```js
class Animal {
  constructor(name) {
    this.name = name;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);
    this.breed = breed;
  }
}
```

`getter` 和 `setter` 使用属性访问与赋值语法，不使用函数调用语法。

## 深拷贝与浅拷贝

展开语法只复制第一层结构；嵌套对象仍然共享引用。对于浏览器支持范围允许的项目，可优先使用 `structuredClone`。

```js
const source = { profile: { name: "Gin" } };
const shallow = { ...source };
const deep = structuredClone(source);

shallow.profile.name = "Changed"; // source 同时改变
deep.profile.name = "Independent"; // source 不受影响
```

## 防抖与节流

- 防抖：停止触发一段时间后执行，适用于搜索提示、自动保存。
- 节流：固定时间窗口最多执行一次，适用于滚动加载、鼠标移动。

```js
function debounce(fn, delay) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}
```
