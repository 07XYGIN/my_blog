## 环境与项目管理（uv）

```bash title="uv 常用命令" showLineNumbers
uv venv .venv                  # 新建虚拟环境
uv venv --python 3.11 .venv    # 根据特定版本新建虚拟环境
```

## 基础语法

### enumerate

用于遍历列表/元组/字符串，同时获取索引和值。

`enumerate(iterable, start=0)`

| 参数 | 说明 |
| --- | --- |
| `iterable` | 任何可迭代对象（列表、元组等） |
| `start` | 索引起始值，默认为 `0` |

```python title="enumerate_demo.py" showLineNumbers
fruits = ["苹果", "香蕉", "橙子"]

for index, fruit in enumerate(fruits, start=1):
    print(f"索引: {index}, 水果: {fruit}")
```

### 模块化

最简单的导入：同目录下 `from a import add`。

```python title="a.py / main.py" showLineNumbers
# a.py
def add(a, b):
    return a + b


# main.py
from a import add

add(1, 2)
```

导入子包中的模块：`src/a.py` 通过包名导入（在项目根目录下运行 `main.py`）。

```python title="src/a.py / main.py" showLineNumbers
# src/a.py
value = 1


# main.py
import src.a as a_module   # 导入整个模块，通过 a_module.value 访问
from src.a import value    # 或者直接导入变量

print(a_module.value, value)
```

同目录下直接 `import config`。

```python title="src/mysql/main.py / src/mysql/config.py" showLineNumbers
# src/mysql/main.py
import config

data = config.database


# src/mysql/config.py
database = "mysql://localhost:3306"
```

包内相对导入：`from .mysql.main import ...`。被当作包导入的模块，内部也要改用相对导入，否则找不到同级的 `config`。

```python title="src/a.py / src/mysql/main.py" showLineNumbers
# src/mysql/main.py
from . import config

data = config.database


def connect_to_db():
    return data


# src/a.py
from .mysql.main import connect_to_db

print(connect_to_db())
```

<Callout type="warning" title="相对导入只能在包内使用">
含有相对导入的文件不能直接 `python src/a.py` 运行，会报 `attempted relative import with no known parent package`。需要在项目根目录用 `python -m src.a` 以包的方式运行。
</Callout>

### 异常

#### try-except

```python title="try_except.py" showLineNumbers
try:
    number = int(input("请输入除数："))
    result = 10 / number
except ZeroDivisionError:    # 可以按错误类型分别处理
    print("除数不能为 0")
except ValueError as e:      # as e 获取异常对象
    print(f"输入的不是整数：{e}")
else:      # 没有异常时执行
    print(f"结果：{result}")
finally:   # 不管有没有异常都执行
    print("计算结束")
```


| 模式 | 说明 | 文件不存在 | 文件存在 |

### Pydantic

用于数据校验。`EmailStr` 依赖 `email-validator`，需要一并安装。

```bash
uv add "pydantic[email]"
```

```python title="pydantic_demo.py" showLineNumbers {10,11,12,13,15}
from pydantic import BaseModel, EmailStr, Field, field_validator

# BaseModel 类似 TypeScript 的 interface
# Field 用于声明数值范围、字符串正则等校验规则
# field_validator 用于自定义校验单个字段
# EmailStr 校验邮箱地址


class User(BaseModel):
    username: str = Field(min_length=2, max_length=20, description="用户名")
    email: EmailStr = Field(description="邮箱")
    age: int = Field(ge=0, le=150, description="年龄")
    password: str = Field(min_length=6, description="密码")

    @field_validator("username")
    @classmethod
    def username_must_not_contain_space(cls, value: str) -> str:
        if " " in value:
            raise ValueError("用户名不能包含空格")
        return value
```

`Field` 常用约束：

| 参数 | 含义 |
| --- | --- |
| `min_length` | 最小长度 |
| `max_length` | 最大长度 |
| `ge` | 大于等于 |
| `le` | 小于等于 |
| `gt` | 大于 |
| `lt` | 小于 |
| `pattern` | 字符串需要匹配的正则 |

敏感字段（如密码）可以使用 `SecretStr`：打印和序列化时会显示为 `**********`，需要真实值时调用 `.get_secret_value()`。

```python title="yaml_demo.py" showLineNumbers {6,9}
from pathlib import Path

import yaml

# 当前文件位于「项目根目录/子目录」下时，向上两级即项目根目录
PROJECT_ROOT = Path(__file__).resolve().parent.parent


def get_yaml(filename: str = "keywords.yaml") -> dict:
    config_path = PROJECT_ROOT / filename
    with open(config_path, "r", encoding="utf-8") as f:
```

### logging

`logging` 是 Python 标准库，无需额外安装。

```python title="logging_demo.py" showLineNumbers
import logging

logging.basicConfig(
    # 日志级别：DEBUG < INFO < WARNING < ERROR < CRITICAL
    # 设置 DEBUG 就能看到所有级别的日志
    level=logging.DEBUG,

    # 日志格式
    format="%(asctime)s - %(name)s - %(levelname)s - %(filename)s:%(lineno)d - %(message)s",

    # 时间格式
    datefmt="%Y-%m-%d %H:%M:%S",

    # 输出到文件，不设置默认输出到控制台
    filename="app.log",

    # 文件写入模式 a=追加 w=覆盖（仅在设置了 filename 时可用）
    filemode="a",

    # 编码（仅在设置了 filename 时可用，否则会抛出 ValueError）
    encoding="utf-8",
)
```

`basicConfig` 只在 root logger 还没有 handler 时生效，重复调用不会覆盖已有配置，需要强制重置时加上 `force=True`。

`format` 常用占位符：

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `%(asctime)s` | 时间 | `2024-01-01 12:00:00` |
| `%(levelname)s` | 级别 | `DEBUG` / `INFO` / `WARNING` / `ERROR` |
| `%(filename)s` | 文件名 | `main.py` |
| `%(lineno)d` | 行号 | `42` |
| `%(funcName)s` | 函数名 | `login` |
| `%(name)s` | logger 名称 | `root` |
| `%(message)s` | 日志内容 | 自定义 |

## 常用装饰器

### @property

将方法变成属性，默认只读。

```python title="property_demo.py" showLineNumbers
from datetime import datetime


class Person:
    def __init__(self, birth_year: int):
        self.birth_year = birth_year

    def get_age(self) -> int:  # 普通方法，使用时需要加括号
        return datetime.now().year - self.birth_year

    @property
    def age(self) -> int:      # 加了 @property 后，方法变成属性
        return datetime.now().year - self.birth_year


person = Person(2000)
person.get_age()  # 调用方法
person.age        # 像访问属性一样访问，不加括号
```

### @dataclass

自动生成 `__init__`、`__repr__`、`__eq__` 等方法。

```python title="dataclass_demo.py" showLineNumbers
from dataclasses import dataclass, field


@dataclass
class Tool:
    name: str
    tags: list[str] = field(default_factory=list)  # 可变默认值必须用 default_factory

    def get_display_name(self, prefix: str) -> str:
        return f"{prefix}-{self.name}"


item = Tool("join")
print(item)                     # Tool(name='join', tags=[])
print(item == Tool("join"))     # True，__eq__ 自动按字段比较
print(item.get_display_name("tool"))  # tool-join
```

### `*args` 与 `**kwargs`

处理数量不确定的同类型参数时使用 `*`，参数会被收集成元组。

```python title="args_demo.py" showLineNumbers
def concat(*strings):
    result = ""
    for s in strings:  # 不要把循环变量命名为 str，会遮蔽内置的 str()
        result += s
    return result
```

处理数量不确定的关键字参数时使用 `**`，参数会被收集成字典。

```python title="kwargs_demo.py" showLineNumbers
def requests_send(url, **request_options):
    timeout = request_options.get("timeout", 10)
    method = request_options.get("method", "GET")
    headers = request_options.get("headers", {})
    return f"url={url}, timeout={timeout}, method={method}, headers={headers}"
```

### 自定义装饰器

装饰器本质上就是一个接收函数、返回函数的高阶函数，用来在不修改原函数代码的前提下，给它「包」上一层额外的功能。下面是最简写法，实际使用时建议加上 `functools.wraps` 保留原函数的名称和文档（见下方「有参数的装饰器」）。

```python title="decorator_demo.py" showLineNumbers {8}
def log(func):
    def wrapper(*args, **kwargs):
        print(f"调用参数: args={args}, kwargs={kwargs}")
        return func(*args, **kwargs)
    return wrapper


@log  # 相当于 create_user = log(create_user)
def create_user(name, age, city="Beijing", vip=False):
    print(f"{name}, {age}, {city}, VIP={vip}")


create_user("job", 18, city="Shanghai", vip=True)
# 调用参数: args=('job', 18), kwargs={'city': 'Shanghai', 'vip': True}
```

<Details title="有参数的装饰器">

```python title="decorator_with_args.py" showLineNumbers {4,5,6}
from functools import wraps


def my_decorator(**kwargs):        # 第 1 层：用 **kwargs 收集任意关键字参数
    def decorator(func):           # 第 2 层：接收被装饰的函数
        @wraps(func)               # 保留原函数的 __name__、__doc__ 等信息
        def wrapper(*args, **kw):  # 第 3 层：真正执行的包装函数
            print(f"装饰器配置: {kwargs}")
            return func(*args, **kw)
        return wrapper
    return decorator


@my_decorator(times=3, delay=2, name="测试")
def risky_function():
    return "执行成功"


risky_function()
# 装饰器配置: {'times': 3, 'delay': 2, 'name': '测试'}
```
