## python基础复习

## enumerate
用于遍历列表/元组/字符串，获取索引和值
`enumerate(iterable, start=0)`
iterable: 任何可迭代对象（列表、元组等）

start: 索引起始值，默认为0

~~~py
fruits = ['苹果', '香蕉', '橙子']

for index, fruit in enumerate(fruits,start=1):
    print(f"索引: {index}, 水果: {fruit}")

~~~

`**kwargs`:解包字典

注意:不可以在 ** 后面添加参数，只能在前面添加参数，但可以在 ** 后面加**args

~~~python
def a(**kwargs):
    print(kwargs)
a(name="张三", age=25, city="北京") #输出这个字典
~~~

## 1.2 @dataclass
自动生成`__init__`,  `__repr__` , `__eq__`等方法
~~~py
from dataclasses import dataclass
@dataclass
class toolList:
    name:str
    def get_display_namee(self,age):
        obj = {
            "self":self,
            "age":age
        }
        return obj

item = toolList('join')

~~~


~~~py
from passlib.context import CryptContext

pwd_context = CryptContext(schemes=["argon2"], deprecated="auto")
"""
schemes:加密算法
deprecated:标记旧算法过时
"""

def get_psd_hash(pass:str)->str:
"""
返回hash
"""
return pwd_context.hash(pass)

def verify_password(plain_password:str,hashed_password:str)-bool
"""
plain_password :密码
hashed_password:hash
"""
return pwd_context.verify(plain_password, hashed_password)


~~~
