这组笔记从 Java 的对象与类型开始，逐步连接 HTTP、数据库、认证和缓存。示例统一以 Java 17、Spring Boot 3.5.x 为基线；代码中的依赖版本用于说明可对照的 API，不代表最新版本。

## Java 基础

[Java 基础：对象、集合与常用类型](/blog/java-basics)

先分清空集合与 `null`，再理解 `private`、`public`、`final`、`static`、接口、基本类型与包装类。包含可以直接使用 JDK 编译的完整示例，以及 BigDecimal、BigInteger 和日期时间的选择边界。

## Web 与数据库工程

[Spring Boot 与 MyBatis：请求、查询和错误处理](/blog/spring-boot-mybatis)

沿着 Controller → Service → Mapper 看一次请求如何到达数据库。依赖与配置、请求参数、DTO 校验、构造器注入、XML CRUD、统一响应、业务异常与 HTTP 状态放在同一条主线上；PageHelper 分页和一对多查询作为可选增量。

## 登录与 JWT 鉴权

[Spring Security 与 JWT：登录、令牌和权限](/blog/spring-security-jwt)

包含密码哈希与登录校验、JWT 签发和解析、Bearer 过滤器、SecurityContext、401/403 处理以及 Security 配置。必填密钥通过环境变量提供；演示用户存储与生产用户服务的边界单独说明。

## Redis 与 ID

[Spring Boot 的 Redis 缓存与 ID 生成](/blog/spring-redis-identifiers)

包含 Redis 连接、带过期时间的 JSON 缓存、反序列化与异常处理、删除与存在判断，以及通过成熟库生成雪花 ID。实例编号、时钟与前端整数精度是 ID 方案的一部分，不能只复制一个固定的 `nextId()` 配置。

## 学习顺序与组合

Java 基础可以独立阅读；其他三篇沿用 Web 工程的版本与包名。先验证 Web/数据库的请求链路，再按需要接入鉴权与 Redis。鉴权中的令牌撤销只是边界说明，没有混入未完成的黑名单业务。

查具体 API 时直接进入对应主题；需要扩展功能时，先确认它属于请求处理、持久化、认证还是缓存，避免把所有逻辑重新堆进一个工具类。
