## 常用命令

```bash
# 拉取镜像
docker pull redis:6.2

# 查看镜像列表
docker images

# 查看正在运行的镜像
docker ps

# 运行镜像

docker run -d --name redis-1 -p 6379:6379 redis:6.2
# `-d` 表示后台运行，`--name` 用于设置容器名称，`-p 6379:6379` 将容器的 6379 端口映射到本机的 6379 端口。
# 如果本机的 6379 端口已被占用，可改用 `-p 6380:6379`。

```
